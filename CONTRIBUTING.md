# 🙌 Contributing to Light Up Tech Job Resources

Thanks for helping others find opportunities! 💛

## How to add a resource

1. **Fork** this repo.
2. Open the right file:
   - Internships → `job-boards/internships.md`
   - Full-time / new grad → `job-boards/full-time.md`
   - Part-time / remote → `job-boards/part-time-remote.md`
   - Early career programs → `student-programs/early-career-programs.md`
   - Fellowships / diversity → `student-programs/fellowships-diversity.md`
3. Add a row to the table using the same format:
   ```
   | [Name](https://link.com) | One-line description |
   ```
4. Open a **Pull Request** with a short title like `Add: Company X internship program`.

**Not comfortable with Git?** Open an [Issue](../../issues) with the link and a short description and we'll add it.

## Guidelines

- ✅ Free, legit resources that help people get jobs or internships
- ✅ Link to the **official** page whenever possible
- ❌ No paid-to-apply programs, referral spam, or affiliate links
- ❌ No duplicates — search the file first
- 🔗 Found a broken link? Please open an Issue or PR to fix it!
